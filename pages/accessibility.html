Accessibility

Accessibility information, supported interactions, and ways to report barriers.

Accessibility approach

The project aims to provide semantic page headings, readable contrast, keyboard-accessible navigation, a skip-to-content link, visible focus indications, and responsive layouts.

The maze game supports keyboard input and on-screen directional controls. Interactive behavior can differ by device, browser, or assistive technology.

Known limitations and testing status

The project has passed available local source and automated checks, but a comprehensive screen-reader audit, real-device keyboard and touch review, and formal WCAG conformance evaluation have not been completed.

Accordingly, this page does not claim formal WCAG certification or complete compatibility with every assistive technology.

Reporting an issue

If you encounter a navigation barrier, unreadable content, or difficulty operating the game, describe the affected page, browser, device, and steps to reproduce using the author’s linked public source repository.

Please avoid posting sensitive personal information in public issue reports. Accessibility feedback can inform future corrections.
