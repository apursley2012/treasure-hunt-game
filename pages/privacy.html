TREASURE HUNT / SITE INFORMATION

Privacy Policy

How this static portfolio game handles information when you visit and play.

Information used by the game

The browser-based Treasure Hunt game does not require an account, sign-in, or personal profile. Maze positions, difficulty settings, and round progress are held in browser memory during play.

The game does not intentionally send gameplay events or personal information to a project-owned backend, and it does not use a project-operated analytics tracker or advertising SDK in the supplied website code.

Hosting and technical data

The website is designed for static hosting on GitHub Pages. The hosting provider and your browser or network may process technical information such as IP addresses, request details, browser information, and security logs according to their own policies.

This site does not control or make representations about GitHub Pages’ independent data-handling practices. Consult the hosting provider’s privacy documentation for more information.

Cookies, storage, and external destinations

The supplied game does not deliberately set tracking cookies or store game progress in local storage. Refreshing the page resets the current race.

Links to external repositories or services are governed by those destinations’ policies. The site uses locally hosted images and scripts, and requests the Space Grotesk and Sora font stylesheets from Google Fonts. Loading these fonts may transmit your IP address and browser request information to Google; Google’s own privacy practices apply. If the fonts cannot load, the site uses system fallback fonts.

Questions and updates

For privacy questions, use the contact method provided on the author’s linked public source repository. Avoid sending sensitive personal information in a public issue.

This policy describes the supplied static website as of November 1, 2026. If hosting, analytics, forms, or other integrations change, this notice should be reviewed and updated.
